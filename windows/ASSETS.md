# Bundled runtime and model sources

- Electron 45.0.0: official npm package and runtime downloads. Its distribution
  includes Electron/Chromium license notices.
- `sherpa-onnx-node` / `sherpa-onnx-win-x64` 2.0.0: official k2-fsa native bindings,
  Apache-2.0 package license. Source: https://github.com/k2-fsa/sherpa-onnx.
- Quantized chunk-8 KWS model: official
  `sherpa-onnx-kws-zipformer-zh-en-3M-2025-12-20` release. Archive SHA-256
  `68447f4fbc67e70eee3a93961f36e81e98f47aef73ce7e7ca00885c6cd3616a6`.
  Source: https://github.com/k2-fsa/sherpa-onnx/releases/tag/kws-models.
- Silero VAD: official sherpa `asr-models/silero_vad.onnx` release, SHA-256
  `9e2449e1087496d8d4caba907f23e0bd3f78d91fa552479bb9c23ac09cbb1fd6`.
  Sources: https://github.com/k2-fsa/sherpa-onnx/releases/tag/asr-models and
  https://github.com/snakers4/silero-vad (MIT).
- Shared orb: repository `ui/orb`, Three.js and vendored bloom helpers; source and
  MIT license are retained in `assets/orb/vendor/` when packaged.
- App/tray icon: procedural PNG/ICO generated by this project's `scripts/icon.mjs`.
- Synthetic speech fixture: existing Android native-test Jarvis fixture; copied
  into ignored `build/` for tests and excluded from the app package.

`scripts/prepare-assets.mjs` records and verifies individual extracted model hashes
as well as the archive hash. npm dependency integrity is locked in package-lock.json.
