# Central Jarvis configuration

The owner requested all Jarvis configuration inside Hermes's own dashboard on
2026-10-24. The native Jarvis tab is implemented as an external dashboard plugin;
no Hermes core files are changed. The implementation is being delivered in three
checkpoints: control/plugin foundation, gateway synchronization, Android pairing.
Do not treat the foundation alone as a completed phone migration or deployment.

The tab owns recognition/synthesis preferences, ElevenLabs key replacement,
fast/deep profile selection, gateway address, wake/silence/interruption settings,
reboot reminder, vision availability and preferred camera. Native Hermes pages
continue to own model providers, authentication, tools and agent settings.

Keys are write-only in the Jarvis form and remain in the VPS deployment `.env`.
Nonsecret preferences persist in the gateway volume. A private Unix socket connects
the native dashboard plugin and voice gateway to control; no public administration
listener is added. Only the owner-operated SSH dashboard is supported by this
deployment. Configuration intentionally belongs to the shared Jarvis service,
independent of which fast/deep profile is selected in the dashboard.

Pairing uses a private capability generated by the phone. A public identifier is
shown on the phone and in Hermes; approve only the matching request. Approval is
required before the phone receives its existing Android credential over HTTPS.
Requests expire after three minutes, are bounded, and can be claimed once. No API
key, device token or private capability belongs in URLs, logs, screenshots or chat.

The phone migration replaces local preference editors with pairing/connection
status. Permissions still belong to Android, and camera activation stays local and
explicit. Managed preferences are cached for offline wake. Server pipeline changes
require an idle acknowledgement after local playback/follow-up, plus no active
server capture/turn. Phone-only changes retain the existing router/history.

Windows regression commands (Git Bash, from repo root):

```bash
python -m uv run --python 3.12 pytest -W error -q
node --check integrations/hermes-jarvis/dashboard/dist/index.js
export JAVA_HOME="/c/Program Files/Android/Android Studio/jbr"
cd android
./gradlew testDebugUnitTest assembleDebug assembleDebugAndroidTest lintDebug
./gradlew --stop
adb -s emulator-5554 install -r app/build/outputs/apk/debug/app-debug.apk
adb -s emulator-5554 install -r -t app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb -s emulator-5554 shell am instrument -w -r com.openclawchip.jarvis.test/androidx.test.runner.AndroidJUnitRunner
```
